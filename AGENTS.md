# AGENTS.md

## Project Overview

Marketing website for **TechPro Solutions**, a Vietnamese software company. The site advertises four main services: digital advertising, digital transformation, custom software development, and website sales. Built with TanStack Start on Netlify.

## Tech Stack

| Layer | Technology |
|-------|------------|
| Framework | TanStack Start (SSR) |
| Routing | TanStack Router v1 (file-based) |
| Frontend | React 19 |
| Styling | Tailwind CSS 4 (`@import "tailwindcss"` syntax) |
| Icons | Lucide React (already installed) |
| Forms | Netlify Forms (static skeleton in `public/contact-form.html`) |
| Deployment | Netlify (configured via `netlify.toml`) |

## Directory Structure

## Key Conventions

### Routing
- File-based routing via TanStack Router. Routes in `src/routes/` map directly to URLs.
- Nested routes use subdirectories: `src/routes/dich-vu/` → `/dich-vu/*`
- Each route file exports `Route = createFileRoute(...)` — the path string must exactly match the file path.
- The `routeTree.gen.ts` is auto-generated by the TanStack Router Vite plugin at build/dev time. Do not edit it manually.

### Styling
- Tailwind CSS 4: uses `@import "tailwindcss"` (not `@tailwind base/components/utilities`)
- Dark theme: `bg-slate-950` body, `bg-slate-900/50` for alternating sections
- Custom CSS classes in `styles.css`: `.gradient-text`, `.hero-gradient`, `.service-card`, `.animate-float`, `.animate-fade-in-up`
- No `cn()` helper — plain template literals for conditional classes

### Forms
- Contact form at `/lien-he` uses Netlify Forms via AJAX fetch (no full-page reload)
- **Critical:** `public/contact-form.html` must mirror all form fields; Netlify scans static HTML at build time
- Fetch posts to `/contact-form.html` (not `/`) to avoid SSR function interception
- Honeypot field `bot-field` included for spam filtering
- Fields: `name`, `email`, `phone`, `service`, `message`

### TypeScript
- Strict mode. Use `type` keyword for type-only imports.
- Path alias: `@/*` → `src/*`

### SEO
- Each route sets its own `head()` meta via TanStack Router's `head` option on `createFileRoute`
- Root language is `vi` (Vietnamese) in `__root.tsx`

## Adding New Routes

1. Create `src/routes/your-page.tsx`
2. Export `Route = createFileRoute('/your-page')({ component: YourPage })`
3. Add navigation links in `src/components/Header.tsx` and `src/components/Footer.tsx`
4. The router Vite plugin auto-updates `routeTree.gen.ts`

## Non-obvious Decisions

- **Vietnamese-first:** All user-facing content is in Vietnamese. No i18n library — add `react-i18next` if multi-language is needed.
- **No database:** This is a pure marketing/brochure site. Leads go to Netlify Forms, not a DB.
- **Service pages as separate routes (not anchor scroll):** Each service has a dedicated URL for SEO purposes.
- **Pricing displayed openly:** Approximate pricing is shown to qualify leads before contact.
